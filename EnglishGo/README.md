# EnglishGo 🇬🇧

EnglishGo — o‘zbek o‘quvchilari uchun ingliz tilini o‘rganish web-ilovasi.

## Ishga tushirish
1. ZIP faylni oching.
2. `EnglishGo/index.html` faylini brauzerda oching.
3. VS Code orqali istalgan faylni tahrirlashingiz mumkin.

Backend yoki build kerak emas. Natijalar brauzer `localStorage`ida saqlanadi.
